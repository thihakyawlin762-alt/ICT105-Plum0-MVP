# Demo Outline for Final Pitch

## 1. Opening Problem

Many university students struggle to manage multiple assignments, deadlines, and coursework using notebooks, messaging applications, or memory alone. This often leads to missed deadlines, poor organization, and unnecessary stress. Lecturers also have limited visibility into students' assignment progress without a centralized tracking system.

---

## 2. Target User

**Primary Users**
- University students who want to organize assignments, monitor deadlines, and improve time management.

**Secondary Users**
- Lecturers who need to review assignment records, monitor assignment progress, and analyze course performance through a centralized dashboard.

---

## 3. Product Solution

Smart Assignment Tracker is a web-based assignment management system that helps students organize coursework, manage deadlines, and monitor academic progress through an intuitive dashboard. The system also provides a Lecturer Dashboard that enables instructors to review assignment records, monitor completion status, and analyze overall course activity.

---

## 4. Demo Flow

1. Introduce the assignment management problem faced by university students and lecturers.
2. Open the Smart Assignment Tracker Landing Page.
3. Login to the system.
4. Access the Student Dashboard.
5. Create a new assignment.
6. Search and filter assignment records.
7. View assignment details, edit information, and mark an assignment as completed.
8. Open the Lecturer Dashboard to review assignment records and analytics.
9. Demonstrate notifications, dashboard metrics, and course statistics.
10. Summarize the prototype benefits and present the planned improvements before the final release.

## 6. Closing Value Message

Smart Assignment Tracker provides a practical solution for helping university students organize assignments, monitor deadlines, and improve academic productivity while allowing lecturers to review assignment progress through a centralized dashboard. The prototype demonstrates a complete assignment management workflow and will continue to be refined based on user testing and feedback before the final presentation in Lab 14.
