# Access Notes

The prototype does not require:

- Internet connection
- Backend server
- Database server

To use the prototype:

1. Open **index.html** in any modern web browser.
2. Navigate through the homepage.
3. Access the Login page.
4. Enter the Student or Lecturer modules.
5. Assignment data is stored automatically using the browser's LocalStorage.

Authentication is currently simulated and does not perform real account verification because backend implementation is outside the scope of the MVP prototype.

# Prototype Summary

The Smart Assignment Tracker is a functional web-based assignment management prototype developed using HTML5, CSS3, and JavaScript.

The system contains two primary modules.

## Student Module

Students can:

- View Dashboard
- Add Assignments
- Edit Assignments
- Delete Assignments
- Search Assignments
- View Assignment Details
- Track Completed Assignments
- Receive Deadline Notifications
- Monitor Dashboard Statistics

## Lecturer Module

Lecturers can:

- View Assignment Records
- Monitor Assignment Status
- View Student Progress
- Review Course Analytics
- Manage Assignments through the Lecturer Dashboard

---

# Data Handling

Prototype data is stored using the browser's **LocalStorage**, allowing records to persist between browser sessions without requiring a backend database.

For Lab 11 Startup Metrics, additional prototype datasets were created in CSV format for Power BI analysis, demonstrating product metrics, activity logs, and dashboard analytics.
