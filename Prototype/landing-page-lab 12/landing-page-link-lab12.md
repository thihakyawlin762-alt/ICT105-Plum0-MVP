## CTA Used

**Explore the Dashboard and Start Managing Your Assignments Today**

The Call-to-Action (CTA) directs users from the landing page to the Smart Assignment Tracker prototype, allowing them to experience the assignment management system.

## Notes

The landing page serves as the introduction to the Smart Assignment Tracker project. It explains the project purpose, target users, core features, and value proposition before directing users into the working prototype.

The landing page connects directly to the prototype through the CTA button, allowing users to navigate from the promotional landing page to the fully functional Smart Assignment Tracker system.

The prototype demonstrates assignment creation, editing, searching, completion tracking, dashboard analytics, and lecturer management features developed throughout Labs 10–12.
