# Final Demo Script

## Demo Duration

Recommended duration: *5–7 minutes*.

---

## 1. Opening

Good morning, everyone.

Today, we are presenting our project, *Smart Assignment Tracker*, a web-based assignment management system designed for university students and lecturers.

Many students struggle to organize assignments, monitor deadlines, and keep track of academic progress, while lecturers often lack a centralized way to monitor assignment completion.

Our prototype provides a simple and organized platform that helps students manage assignments efficiently while allowing lecturers to monitor assignment records and course progress through a dedicated dashboard.

---

## 2. User Scenario

Imagine a university student who has multiple assignments from different courses with different due dates.

Instead of relying on paper notes or messaging applications, the student uses *Smart Assignment Tracker* to create assignments, monitor deadlines, update progress, and search for records quickly.

At the same time, lecturers can access the Lecturer Dashboard to review assignment records, monitor completion rates, and analyze course progress.

---

---

## 4. Evidence and Validation

The prototype was evaluated through user testing conducted during Lab 13.

Test users completed common assignment management tasks, including creating assignments, searching records, updating assignment status, and reviewing dashboard information.

Feedback showed that users found the workflow easy to understand, while several usability improvements—such as clearer navigation, improved layouts, and better dashboard presentation—were implemented before the final prototype.

---

## 5. Closing

Smart Assignment Tracker demonstrates a complete assignment management workflow that helps students organize coursework, monitor deadlines, and manage academic progress more efficiently.

Throughout Labs 10–14, the prototype has been progressively improved through feature implementation, interface refinement, user testing, and documentation updates.

Future development may include multi-user authentication, cloud database integration, email notifications, and advanced analytics to further enhance the system.
