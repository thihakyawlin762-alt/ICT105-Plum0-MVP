# Landing Page Content

## Project Title

Smart Assignment Tracker

---

## Target User

University students who need an organized way to manage assignments, monitor deadlines, and track academic progress. The system also supports lecturers who want to review assignment records and monitor student progress.

---

## Headline

Stay Organized. Never Miss Another Assignment Deadline.

---

## Subheadline

Smart Assignment Tracker is a web-based assignment management system that helps students organize coursework, monitor deadlines, and track assignment progress through an easy-to-use dashboard. Lecturers can also review assignment records and monitor overall academic progress through a dedicated dashboard.

---

## Problem Statement

Many university students rely on notebooks, messaging applications, or memory to manage assignments. This often results in forgotten deadlines, poor organization, incomplete work, and unnecessary academic stress. Lecturers also have limited visibility into overall assignment progress without a centralized management system.

---

## Solution Description

Smart Assignment Tracker provides a centralized platform where students can add, edit, search, update, and complete assignments while monitoring deadlines through an interactive dashboard. The prototype also includes a Lecturer Dashboard for reviewing assignment records, monitoring student progress, and viewing course analytics. During Lab 12, the prototype is being refined through UI improvements, feature polishing, usability enhancements, and final preparation for project completion.

## Benefits

- Organizes all assignments in one centralized system.
- Helps students avoid missing important deadlines.
- Improves academic productivity through better organization.
- Allows lecturers to monitor assignment progress more efficiently.
- Demonstrates a working web-based prototype that has been progressively enhanced throughout Labs 10–12.

## Responsible Data Message

Smart Assignment Tracker stores only assignment-related information required for demonstrating the prototype. No unnecessary personal or sensitive information is collected. Prototype data is stored locally using the browser's LocalStorage and is used solely for educational purposes within the ICT105 project.
