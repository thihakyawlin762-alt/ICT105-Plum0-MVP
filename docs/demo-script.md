# Demo Script

## Demo Objective

The objective of this demonstration is to show how the Smart Assignment Tracker helps university students organize assignments, monitor deadlines, manage coursework, and improve productivity through a centralized dashboard. The demo also showcases how lecturers can monitor assignment progress and review assignment records using the Lecturer Dashboard.

## Closing Statement

Smart Assignment Tracker provides university students with a centralized platform to organize assignments, monitor deadlines, and manage academic progress while giving lecturers better visibility into assignment completion and student performance. By simplifying assignment management and improving productivity, the system helps create a more organized and efficient learning experience. We invite users to explore the prototype, test its features, and provide feedback to support further improvements before the final MVP release in Lab 14.
