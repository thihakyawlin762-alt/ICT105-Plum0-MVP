## 4. User Feedback Summary

Overall feedback from testers was positive.

Users appreciated:

- Clean and organized dashboard layout.
- Simple assignment creation process.
- Easy navigation between pages.
- Search functionality that quickly located assignments.
- Lecturer Dashboard providing useful assignment statistics.

Suggested improvements included:

- More noticeable navigation buttons.
- Better chart descriptions.
- Stronger notification visibility.
- Improved visual feedback after completing assignments.
- Additional responsive design improvements for smaller screens.

No critical usability problems were discovered during testing.

## 5. Evidence-Based Decision

### Decision

*Ready for Final Improvement*

### Explanation

The Smart Assignment Tracker prototype successfully completed all major testing tasks. Core features such as assignment management, search functionality, dashboard statistics, notifications, and lecturer monitoring worked as expected.

The remaining issues are primarily user interface refinements and usability improvements rather than functional defects. These improvements will be addressed before the Lab 14 final MVP presentation to provide a more polished and user-friendly experience.
