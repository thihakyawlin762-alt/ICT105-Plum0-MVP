# Landing Page Lab 12 Overview

The Smart Assignment Tracker Landing Page was developed during **Lab 12 – Landing Page and Digital Go-to-Market** to introduce the project to potential users before they access the working prototype.

The landing page serves as the first point of contact for university students and lecturers by presenting the project's purpose, identifying the assignment management problems commonly faced in academic environments, and explaining how the Smart Assignment Tracker provides an effective solution.

The page highlights the system's core features, benefits, and value proposition while guiding users toward the working prototype through a clear Call-to-Action (CTA). It also supports the project's digital marketing strategy by providing a simple, informative, and professional introduction that can be shared through university communication channels such as class chat groups, Google Classroom, Microsoft Teams, social media, and QR codes.

The landing page reflects the current implementation of the Smart Assignment Tracker prototype and remains aligned with the Functional Requirements, User Stories, MVP features, and documentation produced throughout ICT105 Labs 03–12.
